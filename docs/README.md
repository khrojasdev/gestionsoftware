# Documentación técnica

La documentación de arquitectura se organiza en `docs/adr/`. La especificación funcional y los contratos de cada fase se agregarán junto con las implementaciones respectivas.

## Estructura inicial

- `adr/`: decisiones técnicas versionadas.
- `../backend/`: API FastAPI y pruebas.
- `../frontend/`: aplicación React/Vite.
- `../seeds/`: datos y plantillas generadas; nunca se escriben en `insumos/`.
